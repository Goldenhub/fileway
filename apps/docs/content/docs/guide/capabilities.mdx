Fileway is intentionally minimal. This page is the overview: exactly what each driver supports today, what is currently in the works, and what you need to build yourself. Deep-dives live in the [uploads](/docs/guide/uploads), [downloads](/docs/guide/downloads), [metadata](/docs/guide/metadata), and [observability](/docs/guide/observability) guides.

## Coverage Matrix

| Capability | `LocalDriver` | `S3Driver` | `CloudinaryDriver` |
|------------|:---:|:---:|:---:|
| Upload via `ReadableStream` | ✅ | ✅ | ✅ |
| Upload cancellation (`AbortSignal`) | ✅ | ✅ | ✅ |
| Upload progress (`onProgress`) | ✅ | ✅ | ✅ |
| True streaming (no full buffering) | ✅ | ✅¹ | <span style={{ color: "var(--color-fd-primary)" }}>✕</span> |
| Multipart upload (large files) | <span style={{ color: "var(--color-fd-primary)" }}>—</span> | ✅ | <span style={{ color: "var(--color-fd-primary)" }}>✕</span> |
| Public URL retrieval (`getUrl`) | ✅ | ✅ | ✅ |
| Pre-signed URLs | <span style={{ color: "var(--color-fd-primary)" }}>✕</span> | ✅ | ✅ |
| Download / read-back | ✅ | ✅ | ✅ |
| Typed errors (`StorageError.code`) | ✅ | ✅ | ✅ |
| Logging & error hooks (`logger`, `onError`) | ✅ | ✅ | ✅ |
| User metadata (`options.metadata`) | <span style={{ color: "var(--color-fd-primary)" }}>✕</span> | ✅ | <span style={{ color: "var(--color-fd-primary)" }}>✕</span> |
| Result metadata (`result.meta`) | ✅ | ✅ | ✅ |
| Object tagging | <span style={{ color: "var(--color-fd-primary)" }}>✕</span> | <span style={{ color: "var(--color-fd-primary)" }}>✕</span> | <span style={{ color: "var(--color-fd-primary)" }}>✕</span> |
| TTL / expiration | <span style={{ color: "var(--color-fd-primary)" }}>✕</span> | <span style={{ color: "var(--color-fd-primary)" }}>✕</span> | <span style={{ color: "var(--color-fd-primary)" }}>✕</span> |
| Lifecycle rules | <span style={{ color: "var(--color-fd-primary)" }}>✕</span> | <span style={{ color: "var(--color-fd-primary)" }}>✕</span> | <span style={{ color: "var(--color-fd-primary)" }}>✕</span> |

Legend: **✅** supported today · **¹** S3 always streams with bounded memory: `aws-chunked` when the size is known, multipart when it is not (see [uploads](/docs/guide/uploads)) · **—** not applicable (streams directly to disk, no parts) · <span style={{ color: "var(--color-fd-primary)" }}>✕</span> not yet supported (in the works).

## Roadmap

In the works and coming next:

- S3 object tagging and metadata read-back (`headObject`)
- Metadata persistence for `LocalDriver` and `CloudinaryDriver`
- TTL / expiration in `UploadOptions` and lifecycle rule management

Tracked alongside in the [changelog](/docs/reference/changelog).
