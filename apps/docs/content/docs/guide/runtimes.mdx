---
title: Cross-Runtime Usage
description: Run BetterPush on Bun, Deno, and Cloudflare Workers
---

BetterPush universal packages (`@betterpush/core`, `@betterpush/driver-s3`, `@betterpush/driver-cloudinary`) contain zero `node:*` imports and work on any JavaScript runtime. Only `@betterpush/driver-local` requires Node.js (uses `node:fs`).

## Bun

Bun has built-in Node.js compatibility and TypeScript support — run scripts directly:

```bash
# S3
S3_BUCKET=my-bucket AWS_ACCESS_KEY_ID=xxx AWS_SECRET_ACCESS_KEY=yyy \
bun run packages/driver-s3/test-upload.mjs

# Cloudinary
CLOUDINARY_CLOUD_NAME=my-cloud CLOUDINARY_API_KEY=xxx CLOUDINARY_API_SECRET=yyy \
bun run packages/driver-cloudinary/test-upload.mjs

# Local (works via Bun's Node API compat)
bun run packages/driver-local/test-upload.mjs
```

Run vitest tests with Bun's test runner:

```bash
bun test
```

## Deno

Deno can import npm packages via `npm:` specifiers:

```bash
deno run --allow-read --allow-env --allow-net \
  packages/driver-cloudinary/test-upload.mjs
```

If workspace resolution fails, use explicit npm paths:

```bash
deno run --allow-read --allow-env --allow-net \
  npm:@betterpush/driver-cloudinary packages/driver-cloudinary/test-upload.mjs
```

`driver-local` is **not supported** on Deno (no `node:fs`).

## Cloudflare Workers

### Vitest (unit tests)

`@betterpush/core` and `@betterpush/driver-cloudinary` already run tests under `@edge-runtime/vm` via vitest. Run:

```bash
pnpm --filter @betterpush/core test
pnpm --filter @betterpush/driver-cloudinary test
```

### Wrangler (integration tests)

Create a minimal worker to test uploads locally:

```bash
npx wrangler init test-worker
```

Add `@betterpush/core` and `@betterpush/driver-s3` as dependencies, then write:

```ts
import { BetterPushClient } from "@betterpush/core";
import { S3Driver } from "@betterpush/driver-s3";

export default {
  async fetch(req: Request): Promise<Response> {
    const client = new BetterPushClient({
      driver: new S3Driver({
        bucket: "my-bucket",
        endpoint: "https://<account>.r2.cloudflarestorage.com",
        region: "auto",
      }),
    });

    const stream = req.body! as ReadableStream<Uint8Array>;
    const result = await client.upload(stream, {
      filename: "upload.txt",
      path: "uploads",
    });

    return Response.json(result);
  },
};
```

Run locally:

```bash
npx wrangler dev
```
