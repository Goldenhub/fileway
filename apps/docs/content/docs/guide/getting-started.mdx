## Basic Usage

```ts
import { BetterPushClient } from "@betterpush/core";
import { LocalDriver } from "@betterpush/driver-local";

const client = new BetterPushClient({
  driver: new LocalDriver({
    directory: "./storage",
    baseUrl: "https://cdn.example.com",
  }),
});

const stream = new ReadableStream({
  start(controller) {
    controller.enqueue(new TextEncoder().encode("file content"));
    controller.close();
  },
});

const result = await client.upload(stream, {
  filename: "readme.txt",
  path: "docs",
  mimeType: "text/plain",
});

console.log(result.id);
console.log(result.url);
console.log(result.path);
console.log(result.size);
```

## API Reference

### `delete(path)`

Deletes a file from the storage backend.

| Parameter | Type | Description |
|-----------|------|-------------|
| `path` | `string` | The file path (as returned by `upload()`) |

**Returns:** `Promise<boolean>` — `true` if the file existed and was deleted, `false` if it didn't exist.

**Behavior across drivers:**

| Driver | Behavior |
|--------|----------|
| `LocalDriver` | Removes the file from disk. Returns `false` if file doesn't exist. Throws if path traverses outside the configured directory. |
| `S3Driver` | Deletes the object from the bucket. Returns `true` regardless of whether the object existed (S3 delete is idempotent). |
| `CloudinaryDriver` | Calls the Cloudinary Destroy API. Returns `true` on success. |

### `getUrl(path)`

Returns a public URL for a stored file.

| Parameter | Type | Description |
|-----------|------|-------------|
| `path` | `string` | The file path (as returned by `upload()`) |

**Returns:** `Promise<string>`

**Behavior across drivers:**

| Driver | Behavior |
|--------|----------|
| `LocalDriver` | Returns `<baseUrl>/<path>`. Defaults to `file://<directory>/<path>`. Set `baseUrl` in production (e.g. `"https://cdn.example.com"`). |
| `S3Driver` | Returns the object URL in the configured bucket (virtual-hosted or path-style based on `forcePathStyle`). |
| `CloudinaryDriver` | Returns the CDN URL based on the public ID, resource type, and version. |

## Type Inference

Each driver returns its own metadata shape:

```ts
import { LocalDriver } from "@betterpush/driver-local";
import { S3Driver } from "@betterpush/driver-s3";

const localClient = new BetterPushClient({
  driver: new LocalDriver({ directory: "./storage" }),
});

const s3Client = new BetterPushClient({
  driver: new S3Driver({ bucket: "my-bucket", region: "us-east-1" }),
});

const localResult = await localClient.upload(stream, { filename: "f.txt" });
localResult.meta.localPath; // string

const s3Result = await s3Client.upload(stream, { filename: "f.txt" });
s3Result.meta.bucket; // string
s3Result.meta.etag;   // string | undefined
```
