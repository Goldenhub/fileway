## Constructor

```ts
new FilewayClient<TDriver extends BaseDriver>(config: FilewayConfig<TDriver>)
```

The type parameter is the driver, inferred from `config.driver`. To annotate a client, use the driver type: `FilewayClient<S3Driver>`.

### `config`

| Option | Type | Description |
|--------|------|-------------|
| `driver` | `BaseDriver` | The storage driver. See [Drivers](/docs/drivers/local). |
| `middlewares` | `MiddlewareHook<TMeta>[]` | Optional. Middleware run around uploads; inline hooks get the driver's metadata type. See [Middleware](/docs/guide/middleware). |
| `logger` | `Logger` | Optional. Structured logger; receives `info` per operation and `error` on failure. See [Observability](/docs/guide/observability#logger). |
| `onError` | `(error, context) => void \| Promise<void>` | Optional. Called (and awaited) before an error is re-thrown. Aborts are skipped. See [Observability](/docs/guide/observability#onerror). |
| `plugins` | `FilewayPlugin[]` | Optional. Event listeners, middleware and routes. See [Plugins and Events](/docs/guide/plugins). |
| `basePath` | `string` | Optional. Where `client.handler` is mounted. Default `"/api/fileway"`. |
| `retry` | `RetryConfig` | Optional. Retries transient failures (`network`, `timeout`, `rate-limited`, `provider-error`, HTTP 429/5xx). See [Observability](/docs/guide/observability#retries). |

## `upload(stream, options)`

Uploads a WHATWG `ReadableStream<Uint8Array>`.

| Param | Type | Description |
|-------|------|-------------|
| `stream` | `ReadableStream<Uint8Array>` | The file bytes. Never buffered whole by Local/S3. |
| `options` | `UploadOptions` | See the options table below. |

Returns `Promise<UploadResult<TMeta>>` where `TMeta` is the driver's metadata type.

An `upload` retries on transient failures only when `options.streamFactory` is provided (see [Retries](/docs/guide/observability#retries)). Before retrying (or failing), it checks whether the object was stored despite the error and, if so, returns it without re-sending (see [Safe retries](/docs/guide/uploads#safe-retries-and-upload-status)). `delete`, `get`, `getUrl`, and `getPresignedUrl` retry automatically.

`UploadOptions`:

| Option | Type | Required | Description |
|--------|------|----------|-------------|
| `filename` | `string` | ✅ | Original file name. |
| `path` | `string` | | Folder/path prefix for the stored object. |
| `mimeType` | `string` | | Content type. |
| `metadata` | `Record<string, string>` | | Provider user metadata (see [Metadata](/docs/guide/metadata)). |
| `size` | `number` | | Known byte length: unlocks zero-buffer streaming (see [Uploads](/docs/guide/uploads)). |
| `signal` | `AbortSignal` | | Cancels the upload in flight (see [Uploads](/docs/guide/uploads#cancelling-uploads)). |
| `onProgress` | `(progress) => void` | | Progress callback (see [Uploads](/docs/guide/uploads#tracking-upload-progress)). |
| `id` | `string` | | Stable upload ID; the stored name is built from it and reused on every retry. Generated per call when omitted. Reusing an ID overwrites that object. |
| `streamFactory` | `() => ReadableStream<Uint8Array>` | | Re-produces the stream for retry attempts. Required to retry an upload (see [Retries](/docs/guide/observability#retries)). Sync-only today; an async (Promise-returning) variant is planned; see [Retrying uploads](/docs/guide/uploads#retrying-uploads). |

## Options for `get`, `delete`, `getUrl` and `getPresignedUrl`

Each takes an optional second argument:

- `signal` (`AbortSignal`): cancels the request in flight and any pending retries, and rejects with an `AbortError`. For `get`, it also stops reading the returned stream.
- The driver's own options, if it has any. For example Cloudinary accepts `{ resourceType, deliveryType }`:

```ts
await client.delete("avatars/u1", { deliveryType: "authenticated", signal });
```

## `get(path, options?)`

Streams a stored file back as `ReadableStream<Uint8Array>` (see [Downloads](/docs/guide/downloads#download--read-back-getpath)). Throws `StorageError("not-found")` when the file does not exist.

## `delete(path, options?)`

Deletes a stored file. Returns `Promise<void>`. Deleting a file that does not exist is not an error; any other failure throws a `StorageError`.

## `getUrl(path, options?)`

Returns the public URL for a stored file (see [Downloads](/docs/guide/downloads#geturlpath)).

## `client.handler`

A web-standard request handler that serves plugin routes under `basePath`: `{ fetch, GET, POST, PUT, PATCH, DELETE, HEAD, OPTIONS }`, all the same function. Mount it with `export const { GET, POST } = client.handler` in Next.js, or `fetch: client.handler.fetch` on Workers, Bun and Deno. See [Plugins and Events](/docs/guide/plugins#routes-and-clienthandler).

## `actor` and `tags`

Every method accepts `actor?: string` and `tags?: Record<string, string>`. They are recorded on the operation's event and never passed to the driver.

## `getUploadStatus(id, options)`

Reports whether the upload with `id` is stored, in progress, or missing, by asking the storage provider. Pass the same `filename` and `path` the upload used.

| Param | Type | Description |
|-------|------|-------------|
| `id` | `string` | The upload's `id`. |
| `options.filename` | `string` | The filename the upload used (its extension is part of the stored name). |
| `options.path` | `string` | The path the upload used. |
| `options.signal` | `AbortSignal` | Cancels the call and any pending retries. |

Returns `{ state: "complete", object }`, `{ state: "pending" }`, `{ state: "missing" }`, or `{ state: "unsupported" }` when the driver cannot report status. See [Safe retries and upload status](/docs/guide/uploads#safe-retries-and-upload-status).

## `list(options?)`

Returns one page of the files under `options.prefix`: `{ objects, folders, cursor? }`. Options: `prefix`, `recursive` (default `false`, one folder level), `limit` (1 to 1000, default 100), `cursor`, `signal`. See [Managing Files](/docs/guide/managing-files).

## `listAll(options?)`

An async iterator over every file under `options.prefix`, following cursors. Same options as `list` without `cursor`.

## `stat(path, options?)`

Returns the stored file's details (`StoredObject`: `size`, `contentType`, `lastModified`, typed `meta`), or `null` when it does not exist.

## `copy(from, to, options?)` and `move(from, to, options?)`

Copy or move a file on the same storage. Return nothing. An existing `to` fails with `StorageError("conflict")` unless `options.overwrite` is `true`. Drivers without a native move copy, then delete. Drivers without the operation throw `StorageError("config")`.

## `getPresignedUrl(path, options?)`

Returns a time-limited, signed download URL. Available on every driver except `LocalDriver`, which throws `StorageError("config")` (see [Downloads](/docs/guide/downloads#pre-signed-urls)).

| Param | Type | Description |
|-------|------|-------------|
| `path` | `string` | Path of the stored file. |
| `options.expiresIn` | `number` | Lifetime in seconds (default `3600`). S3, GCS and Azure allow at most 604800 (7 days); Cloudinary and Supabase accept any positive integer. |
| `options.signal` | `AbortSignal` | Cancels the call. |
